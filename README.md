# CodeAlpha Data Analytics Internship Tasks

This repository contains my work for the CodeAlpha Data Analytics Internship. Each task is in its own folder.

## Tasks
| Task | Folder | Description |
|---|---|---|
| Task 1: Web Scraping | [Task1_WebScraping](Task1_WebScraping) | Scrapes 1,000 books from books.toscrape.com using Python, BeautifulSoup and pandas, then saves a cleaned CSV dataset. |
| Task 2: Exploratory Data Analysis | [Task2_EDA](Task2_EDA) | Analysis of the Olist Brazilian e-commerce dataset using pandas and SQL, with notebooks, queries and written reports. |

## Note
The raw data for Task 2 is not included in this repository because of file size. The Olist dataset is publicly available on Kaggle.
